# FinTrack Android

FinTrack is an Android application for tracking personal income, expenses, budgets, and financial activity.

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Clean Architecture
- Hilt
- Retrofit
- Room Database
- Coroutines and Flow

## Project Status

This project is currently under development.

## Getting Started

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Run the application on an emulator or Android device.
